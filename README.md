# Учебный расчёт рабочей смены бригады агродронов

Здесь опубликованы сводные результаты модели смены и проверка загрузки наземного оборудования. Все данные учебные. Таблица `shift_comparison.csv` содержит длительность смены, площадь работ и пробег машины для каждого варианта. Файл `service_intervals.csv` содержит интервалы использования наземных ресурсов для базового случая.

```sh
python check_shift.py
```

Проверка читает опубликованные таблицы, проверяет отсутствие пересечений интервалов у каждого рабочего места и считает разницу между вариантами. В базовом примере на одном и том же объёме работ смена занимает 580,2 или 560,2 минуты, а машина проезжает 60 или 50 км. Вариант с кратчайшим пробегом даёт то же время, что и лучший из рассмотренных. В файле `model_checks.json` сохранена сводка проверок исходной модели. Публичный пример позволяет проверить результаты сравнения и работу наземных ресурсов; полевых измерений в нём нет.
